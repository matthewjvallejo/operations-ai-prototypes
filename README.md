# Operations + AI Prototypes

I am an operations leader who uses AI and modern tools hands-on to analyze problems, test ideas, prototype practical solutions, and improve customer and business operations.

This repository is a small portfolio of sanitized examples showing how I think about operational problems. The focus is not on software engineering for its own sake. The focus is on using technology where it can remove friction, improve visibility, strengthen customer outcomes, improve communication, or help teams move faster.

## How I work

- Start with the operating problem, not the tool.
- Get close enough to the work to understand what is actually happening.
- Look for patterns, recurring issues, communication breakdowns, and unnecessary friction.
- Use AI, automation, and other technology where they create practical value.
- Test the smallest useful change.
- Learn from the result and expand what works.

## Tools and platforms I have used

My hands-on work has included tools such as ChatGPT, Gemini, Microsoft Copilot, Replit, GitHub, Microsoft 365, SharePoint, CRM platforms, and other operational systems.

I do not present myself as a software engineer. My strength is using technology as an operator: understanding the problem, learning enough to work effectively with the tools, prototyping solutions, and connecting people, process, communication, and technology to improve outcomes.
